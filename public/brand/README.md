# Nirmik Ukani — NU Fold

An original shared-stem NU monogram: an angular N folds into the rounded base of a U. The standalone icon and full-name lockup are SVG vectors. Name lettering is outlined from Space Grotesk Medium, the portfolio's existing heading family, so it does not rely on an installed or downloaded font. The custom monogram is drawn specifically for this portfolio.

- nirmik-ukani-icon.svg: transparent icon.
- nirmik-ukani-wordmark.svg: transparent icon and outlined Nirmik Ukani name.
- ../favicon.svg and ../favicon-light.svg: small-size dark/light favicon variants.

Standalone SVGs adapt to the viewer's color-scheme preference. Website logos use the exact existing theme variables. The website favicon switches with the website theme toggle. No new palette or runtime font dependency was introduced.

Keep proportions intact and allow clear space around the mark. SVG outlines remain sharp at any size. The favicon has its own compact, high-contrast tile.

Typography source: https://github.com/floriankarsten/space-grotesk (SIL Open Font License). No font files or build-only tools are shipped with the website.
